Report: [`4_Evaluation_Niyaaz_Eduardo_Thiago_Priyansh.pdf`](4_Evaluation_Niyaaz_Eduardo_Thiago_Priyansh.pdf)
(ACM `sigconf`, two pages). The code that produces every number, table and figure is in
[`../proposed-solution`](../proposed-solution) (Section 7.1 of its README).

| File | Content |
|---|---|
| `main.tex` | LaTeX source of the report (compiles with `pdflatex` on Overleaf, or `xelatex`) |

| `Bibliography.bib` | references of the report (`main.tex` also keeps an inline copy) |

| `figures/rq2_sensitivity.pdf`, `figures/label_set_confusion.pdf` | Figures 1 and 2, generated by `scripts/make_m4_figures.py` |

## Reproduce

From the repository root (or from `proposed-solution/`):

```bash
bash reproduce_m4.sh
```

The script creates `proposed-solution/.venv`, installs the packages, runs the 26 tests, runs the
cross-validated experiment on the bundled sample (about 3 minutes on a laptop), checks the hash of the
test predictions against `proposed-solution/evaluation/results/m4_sample/EXPECTED_SHA256`, and rewrites
the figures and the two tables in this folder from the new results. Recompiling `main.tex` then gives the
same report. Expected end of the output:

```
== reproducibility check PASSED (m4_sample): identical to the reported run (c8c2b0fd9803...)
```

The hash matches with the exact versions in `proposed-solution/requirements-lock.txt` (Python 3.12 or
3.13, chosen automatically when available). With Python 3.10 or 3.11 the script installs compatible
versions; the run completes, and the last decimals may differ.
